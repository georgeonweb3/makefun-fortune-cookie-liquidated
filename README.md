A fortune cookie for a crypto trader who has just been liquidated, written to make him laugh instead of cry: "At 3:12 a.m. your stop-loss slept, your long died, and the exchange sent flowers shaped like your balance: zero." — 112 characters, 19 words, three beats (the stop-loss asleep, the long dead, the exchange sending its condolences in the shape of nothing) and the punch landing on the last word. Built by an AI agent for make.fun's "Fortune Cookie for the Liquidated Trader" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the fortune to `/output/entry.txt`: UTF-8, 1–160 characters, at most 20 words, deterministic, no network at run time. The program validates the line against the competition's gate and reads the file back before finishing, so a bad line fails loudly instead of shipping silently.
